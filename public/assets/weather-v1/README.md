# Weather backgrounds v1

Generated with the built-in image generation tool on 2026-10-16, using the approved light weather concept board as a style reference. Each background was generated individually. No board was sliced and no text is baked into the images. Original dimensions are preserved; WebP export changes file format only.

The app overlays live server-provided weather data. Historical weather labeling and weather-data attribution remain in the UI. Rain-plan actions remain in the itinerary, not in the weather tiles.

## Common generation prompt

Use case: illustration-story. Create ONE production UI background image for a very small compact weather tile, landscape aspect ratio 2.2:1. Match the attached approved concept board's LIGHT pastel weather background style. This output is a single full-bleed weather background asset, NOT a screenshot, NOT a card with text, NOT a grid. No words, numbers, labels, UI elements, borders, corner rounding or shadows. LEFT 40% must be a very light almost uniform pastel area to protect overlaid dark-navy text, with artwork concentrated in RIGHT 50% and gently blending toward center. Refined soft layered vector-like weather art, restrained subtle tonal depth, mature calm polished product UI. The art must remain recognizable at 100x48px, use few bold forms and no fine details. No people, buildings, landscapes, mascots. Keep pale light tones, no dark backgrounds. Use the corresponding tile in the reference for style, but REMOVE all typography and all UI.
