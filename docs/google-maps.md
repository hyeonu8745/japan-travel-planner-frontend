# 일정 지도 설정 — ① 단계

지도는 `@vis.gl/react-google-maps`를 사용합니다. React 컴포넌트와 지도 훅을 제공하여 날짜별 범위 조정과 다음 단계의 타임라인 연동에 적합합니다.

1. Google Cloud에서 Maps JavaScript API를 사용 설정합니다.
2. 백엔드용 키와 별도로 브라우저용 키를 생성합니다. API 제한은 Maps JavaScript API, 웹사이트 제한은 `http://localhost:5173/*`로 설정합니다. 실제 접속 주소가 다르면 해당 주소도 허용해야 합니다.
3. 프로젝트 루트의 `.env`에 다음 값을 직접 추가합니다. 키를 채팅이나 저장소에 공유하지 않습니다.

```dotenv
VITE_GOOGLE_MAPS_API_KEY=브라우저용_키
```

4. 개발 서버를 재시작하고 `http://localhost:5173`에서 일정 보기를 엽니다.

현재 범위: 왼쪽 지도·오른쪽 일정, 모바일 위 지도·아래 일정, 날짜별 핀과 fitBounds, 숙소 집 아이콘, 방문 순서 번호, 관광지·점심·저녁 색상, 숙소부터 잇는 직선, 이동시간 툴팁. AI 대화는 상단 버튼으로 열 수 있습니다. 키 미설정·지도 오류는 지도 영역에만 안내합니다.

지도 핀과 타임라인의 양방향 선택·상세 열기는 ② 단계, 일정 수정 후 동기화 검증은 ③ 단계에서 진행합니다.

확인: 날짜 탭을 바꾸면 이전 핀·선이 사라지고 선택한 날의 전체 장소가 보이는지, 모바일에서 지도가 위에 표시되는지 확인합니다. 실제 Google 지도 타일·브라우저 키 인증은 로컬 키 설정 후 확인해야 합니다.
